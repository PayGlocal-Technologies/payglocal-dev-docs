| | On-Demand SI | Auto Debit SI |
|---|---|---|
| Debit trigger | Merchant initiates each payment | PayGlocal auto-debits on schedule |
| Amount type | Fixed or variable | Fixed only |
| `startDate` required | No | Yes |
| `mandateId` storage | Required (merchant stores) | Required (merchant stores) |
