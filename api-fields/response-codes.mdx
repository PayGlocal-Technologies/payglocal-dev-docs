## Overview

All PayGlocal API responses include a `reasonCode` field. These codes provide precise information about the outcome of a transaction — whether successful, declined, or errored.

---

| `GL-201-008` | Processor Error |

## Common Decline Actions

| Reason Code | Recommended Action |
|-------------|-------------------|
| `GL-201-007` (Card expired) | Ask customer to use another card |
| `GL-201-009` (Insufficient funds) | Ask customer to use another payment method |
| `GL-201-010` (Lost/stolen card) | Do not retry; contact issuer if needed |
| `GL-201-015` (General Decline) | Verify customer identity; ask for another card |
| `GL-201-022` (Declined by Risk) | Check customer profile; confirm identity |
| `GL-400-002` (Invalid data) | Fix request field values and retry |
| `GL-400-004` (Card type not enabled) | Contact PayGlocal to enable the card type for your MID |
| `GL-501-000` (System error) | Retry after some time |
