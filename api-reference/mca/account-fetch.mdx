---
title: "Fetch Virtual Accounts"
description: "Retrieve virtual account details for a fully activated merchant, grouped by collection label and currency."
openapi: "GET /gcc/v3/merchants/{merchantId}/ffms/virtualAccounts"
---

## When to Use

Call this after a merchant is **fully activated** on PayGlocal to retrieve their assigned global virtual accounts. Accounts are grouped by collection label (e.g. `general`) and within each label by currency code. Do not call this endpoint during merchant onboarding or before activation is confirmed — the response will be empty or return an error. Use the merchant dashboard or the merchant status API to verify activation state before calling.

<Note>
  Returns data only for activated merchants. Calling for a merchant still in onboarding or pending review returns HTTP 401.
</Note>

## Response Structure

The `data` object is a two-level map:

```
data
└── <collection_label>        (e.g. "general")
    └── <currency_code>       (e.g. "USD", "AUD", "GBP")
        └── VirtualAccount    (account number, bank name, routing code, etc.)
```

## Example

<CodeGroup>

```http Request
GET /gcc/v3/merchants/<MERCHANT_ID>/ffms/virtualAccounts HTTP/1.1
Host: api.payglocal.in
x-api-key: <API_KEY>
```

## Error Scenarios

| Scenario | HTTP Code |
|----------|-----------|
| `merchantId` is not valid | `400` |
| Merchant is not activated | `401` |
| Missing or invalid `x-api-key` header | `401` |
| Caller does not have permission for this merchant | `403` |
| `merchantId` not found | `404` |
