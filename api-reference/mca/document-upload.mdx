---
title: "Upload Compliance Document"
description: "Upload a compliance document for an MCA account using multipart/form-data."
openapi: "POST /gcc/v1/mca/document"
---

## When to Use

Call this endpoint to submit a compliance document (such as a business registration certificate, identity proof, or agreement) for an MCA account. Use it during the merchant onboarding or compliance review process when PayGlocal requests supporting documentation. Do not call this endpoint for transaction-level document uploads — use the presigned-URL flow for those. Ensure the `documentType` value matches the document category indicated in your onboarding checklist before uploading.

## Example

<CodeGroup>

```http Request
POST /gcc/v1/mca/document HTTP/1.1
Host: api.payglocal.in
x-api-key: <API_KEY>
Content-Type: multipart/form-data; boundary=----FormBoundary

------FormBoundary
Content-Disposition: form-data; name="documentType"

BUSINESS_REGISTRATION
------FormBoundary
Content-Disposition: form-data; name="file"; filename="registration.pdf"
Content-Type: application/pdf

<binary file content>
------FormBoundary--
```

```json Response (200)
{
  "status": "SUCCESS",
  "data": {
    "documentId": "doc_a1b2c3d4e5f6",
    "documentType": "BUSINESS_REGISTRATION",
    "uploadedAt": "2026-06-09T10:30:00Z",
    "message": "Document uploaded successfully."
  }
}
```

</CodeGroup>

## Error Scenarios

| Scenario | HTTP Code |
|----------|-----------|
| Missing or invalid `documentType` field | `400` |
| Missing file part in the request | `400` |
| Invalid or missing `x-api-key` header | `401` |
| Caller does not have permission for this MCA account | `403` |
| MCA account not found | `404` |
| Document of this type already uploaded | `409` |
| Internal server error | `500` |
