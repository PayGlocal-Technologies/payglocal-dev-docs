<Note>
  This API is for **Partners** onboarding their own sub-merchants onto PayGlocal. If you are a merchant looking to accept payments, see [Checkout Flow (PayCollect)](/api-reference/payments-v2/paycollect/overview) or [Seamless Flow (PayDirect)](/api-reference/payments-v2/paydirect/overview) instead.
</Note>

## Overview

The PayGlocal Onboarding API lets partners programmatically onboard merchants. The flow is sequential — each step must complete before the next.

For authentication, see [Onboarding Authentication](/authentication).

## Onboarding Flow

```
Partner System                          PayGlocal API
      │                                       │
      │  POST /onboard  ─────────────────────▶│  Creates merchant record
      │◀────────────────  onboardingId  ───────│
      │                                       │
      │  PUT /business-details ──────────────▶│
      │  PUT /beneficial-owner ──────────────▶│
      │  PUT /bank-details ──────────────────▶│  Penny drop validation
      │  PUT /auth-signatory ────────────────▶│
      │  PUT /docs (repeat per doc) ─────────▶│
      │  PUT /products ──────────────────────▶│
      │                                       │
      │  PUT /verification/{id}/redirect ────▶│  Generates VKYC URL
      │◀──────────────── redirectLink ──────────│
      │                                       │
      │  GET /status ────────────────────────▶│  Confirm final outcome
      │◀─────────────────────────────────────│
```

<Steps>
  <Step title="Create Onboarding">POST /onboard → returns `onboardingId`</Step>
  <Step title="Update Business Details">PUT /business-details</Step>
  <Step title="Add Beneficial Owner">PUT /beneficial-owner</Step>
  <Step title="Update Bank Details">PUT /bank-details</Step>
  <Step title="Update Authorised Signatory">PUT /auth-signatory</Step>
  <Step title="Upload Documents">PUT /docs (one call per document)</Step>
  <Step title="Configure Products">PUT /products</Step>
  <Step title="Trigger Verification">PUT /verification/{id}/redirect → returns `redirectLink`</Step>
  <Step title="Poll Status">GET /status until APPROVED or RFI</Step>
</Steps>

## Endpoint Index

| Step | Endpoint | Purpose |
|------|----------|---------|
| 1 | [Create Onboarding](/api-reference/create-onboarding) | Start a new merchant onboarding application — returns `onboardingId` |
| 2 | [Update Business Details](/api-reference/update-business-details) | Submit company information |
| 3 | [Add Beneficial Owner](/api-reference/add-beneficial-owner) | Submit UBO details |
| 4 | [Update Bank Details](/api-reference/update-bank-details) | Submit bank account for settlements |
| 5 | [Update Auth Signatory](/api-reference/update-auth-signatory) | Submit authorised signatory details |
| 6 | [Upload Documents](/api-reference/upload-documents) | Upload KYC documents |
| 7 | [Configure Products](/api-reference/configure-products) | Enable payment products for the merchant |
| 8 | [Get Verification Redirect](/api-reference/get-verification-redirect) | Trigger VKYC/DigiLocker verification |
| 9 | [Get Status](/api-reference/get-status) | Poll onboarding and merchant status |
| — | [Get Business Categories](/api-reference/get-business-categories) | Lookup table for `natureOfBusiness` field |
