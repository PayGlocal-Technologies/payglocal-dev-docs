---

## When to Use

Poll this endpoint to check the current lifecycle state of a transaction. The `{id}` path parameter accepts either the PayGlocal `gid` (e.g., `gl-13bbd3c4...`) or your `merchantUniqueId` from the original request.

PayGlocal also posts async updates to your `merchantCallbackURL` on terminal transitions. **We still recommend calling status after every GPI** for reconciliation. For Payments V2 (PayDirect / PayCollect) with response examples by payment method, see [Get transaction status](/api-reference/payments-v2/common/get-transaction-status).

## Transaction Status Values

| Status | Final? | Description |
|--------|--------|-------------|
| `CREATED` | No | Transaction created, awaiting redirect |
| `INPROGRESS` | No | Customer on PayGlocal payment page |
| `AUTHORIZED` | No | Authorized by issuer |
| `SENT_FOR_CAPTURE` | Yes | Payment captured — settlement in progress |
| `ABANDONED` | Yes | Customer closed/timed out payment |
| `ISSUER_DECLINE` | Yes | Declined by card issuer |
| `CUSTOMER_CANCELLED` | Yes | Customer cancelled on PayGlocal page |
| `AUTHENTICATION_TIMEOUT` | Yes | 3DS authentication timed out |
| `GENERAL_DECLINE` | Yes | Declined by risk system |
| `REQUEST_ERROR` | Yes | Fix request fields and retry |
| `SYSTEM_ERROR` | Yes | Retry after some time |
| `CONFIG_ERROR` | Yes | Contact PayGlocal support |

## Example

<CodeGroup>

```json Request
GET /gl/v1/payments/gl-13bbd3c4-0000-0000-0000-000000000001/status HTTP/1.1
Host: api.payglocal.in
x-gl-merchantId: <MERCHANT_ID>
x-gl-reqid: req-0001
x-gl-ts: 1700000000000
x-gl-enc: <RSA_JWS_SIGNATURE>
Content-Type: application/json
```

```json Response (200)
{
  "status": "SUCCESS",
  "httpStatusCode": 200,
  "message": "Payment transaction details fetched successfully.",
  "data": {
    "gid": "gl-13bbd3c4-0000-0000-0000-000000000001",
    "merchantUniqueId": "ORD-20240101-001",
    "paymentType": "CARD",
    "status": "SENT_FOR_CAPTURE",
    "amount": 100.00,
    "currency": "INR",
    "merchantCallbackURL": "https://merchant.example.com/callback"
  }
}
```

</CodeGroup>

## Error Scenarios

| Scenario | HTTP Code |
|----------|-----------|
| Invalid or missing RSA JWS headers | 401 |
| `{id}` not found for this merchant | 404 |
| Malformed GID / merchantUniqueId format | 400 |
| Rate limit exceeded | 429 |
| Upstream system error | 500 |
