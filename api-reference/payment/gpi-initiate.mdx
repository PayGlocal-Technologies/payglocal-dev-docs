## When to Use

Use this endpoint when your integration is **PayDirect** — you collect full card details from
the customer on your own page and send them directly in the API request.

**You must be PCI DSS certified** to use this flow. If you are not PCI certified, use
[Initiate Payment (PayCollect)](/api-reference/payment/gpi-paycollect) instead, where
PayGlocal collects card details on its hosted page.

<Info>
  The request body structure is **identical for domestic and international cards**. However nested
  fields become mandatory still depends on the transaction — for example, `riskData` is required
  for international card transactions and is dependent on merchant line of business.
</Info>

## Notes

- `merchantCallbackURL`: Payers are redirected to this URL post payment completion.
- Include standingInstruction to set up a recurring mandate alongside this payment, for more details refer to standing instructions section.
- On success the response contains `data.redirectUrl` — redirect the customer's browser to it via HTTP GET to complete 3DS / step-up.
