## When to Use

Use this endpoint when your integration is **PayDirect** — you collect full card details from the customer and send them in the request. You must be PCI DSS compliant to use this endpoint.

For non-PCI entities, see [Initiate Payment (PayCollect)](/api-reference/payment/gpi-paycollect).

## Notes

- **Domestic and international:** The request body uses the **same JSON structure** in both cases. Which nested fields are mandatory still depends on the transaction—for example, `riskData` is required for international card transactions.
- `merchantCallbackURL` is where PayGlocal will POST the customer after payment completion.
- Include `standingInstruction` to set up a recurring mandate alongside this payment.
- `riskData` is required for international card transactions.
- On success the response contains `data.redirectUrl` — redirect the customer's browser to it via HTTP GET to complete 3DS / step-up.
