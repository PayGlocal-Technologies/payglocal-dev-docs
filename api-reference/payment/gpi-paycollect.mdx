## When to Use

Use PayCollect if you are **not PCI DSS certified**. You send minimal transaction data; PayGlocal collects card details and payment method selection from the customer on its hosted page.

<Warning>
  PayCollect does **not** support setting up Standing Instructions for cards.
</Warning>

## UPI (India)

Hosted PayCollect is the standard entry point for **UPI** in India: your server calls this endpoint with amount and callback URL, then sends the customer to `redirectUrl`. For the customer journey and funds flow see [UPI](/payments/types/upi-overview). For **UPI Intent** request/response details (including optional `billingData` / `riskData` and the post-success `statusData` payload), see [UPI Intent](/api-reference/payment/upi-intent).

## For Alternative Payment Methods

PayGlocal supports global alternative payment methods (iDeal, Sofort, Trustly, giropay, EPS, wallets, BNPL) for merchants exporting outside India. These require `riskData.shippingData.addressCountry` and `emailId`:

```json
{
  "merchantTxnId": "23AEE8CB6B62EE2AF07",
  "paymentData": {
    "totalAmount": "89",
    "txnCurrency": "INR"
  },
  "riskData": {
    "customerData": {
      "merchantAssignedCustomerId": "11230092"
    },
    "shippingData": {
      "addressCountry": "US",
      "emailId": "customer@example.com"
    }
  },
  "merchantCallbackURL": "https://www.yoursite.com/callback"
}
```

## Example

<CodeGroup>

```json Request
{
  "merchantTxnId": "TXN20240608001",
  "paymentData": {
    "totalAmount": "500.00",
    "txnCurrency": "INR"
  },
  "merchantCallbackURL": "https://www.yoursite.com/callback"
}
```

```json Response (200)
{
  "status": "SUCCESS",
  "message": "Transaction initiated successfully",
  "data": {
    "merchantTxnId": "TXN20240608001",
    "gid": "PAYGLOCAL_TXN_001",
    "redirectUrl": "https://pay.payglocal.in/checkout?token=abc123",
    "status": "INITIATED"
  }
}
```

</CodeGroup>

## Error Scenarios

| Scenario | HTTP Code |
|---|---|
| Missing or invalid `merchantTxnId` | 400 |
| Missing `paymentData.totalAmount` or `txnCurrency` | 400 |
| Invalid or expired JWS signature | 401 |
| Merchant account not found or inactive | 403 |
| Duplicate `merchantTxnId` for the same merchant | 409 |
| Downstream payment processor unavailable | 502 |
