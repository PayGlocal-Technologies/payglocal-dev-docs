## Overview

PayCollect is PayGlocal's hosted checkout. Customers are redirected to a PayGlocal-hosted payment page — your server never handles raw card data, minimizing PCI DSS scope (SAQ A eligible).

**Flow:** Merchant server calls GPI → PayGlocal returns `redirectUrl` → browser redirects → customer pays → PayGlocal POSTs x-gl-token to your `merchantCallbackURL`.

## Authentication

All PayCollect requests require RSA JWS signing. See [Authentication](/api-reference/payments-v2/common/authentication) for headers and signing details.
