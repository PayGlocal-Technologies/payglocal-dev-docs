## What is GPI?

**GPI (PayGlocal Payment Initiate)** is the API call that **starts a PayDirect payment**. You send transaction and card (or token) data in one request; PayGlocal returns a `gid` and a `redirectUrl`. Send the customer to that URL to complete 3DS, then read the outcome from your callback or the status API.

---

## When to Use

Use PayDirect GPI when you are collecting **raw card data or a network token** directly from the customer and need a one-step sale (immediate capture intent) with 3DS step-up. Choose this endpoint over PayCollect GPI when your integration handles card entry on your own checkout form rather than redirecting the customer to a PayGlocal-hosted page. If you need UPI, net banking, or global alternative payment methods, use [PayCollect GPI](/api-reference/payments-v2/paycollect/gpi) instead. For authorize-only (capture later) flows, use the PayDirect Authorize endpoint.

---

## Supported payment methods

| Method | Domestic | International |
|--------|:--------:|:-------------:|
| Cards | ✓ | ✓ |
| Apple Pay | — | ✓ |

PayDirect GPI does not support UPI, net banking, or global alternative payments — use [GPI](/api-reference/payments-v2/paycollect/gpi) for those.

## Notes

- In **Request body** → `paymentData`, send **`cardData` or `tokenData`** (exactly one is mandatory).

## Error Scenarios

| Scenario | HTTP Code |
|----------|-----------|
| Invalid request fields or error processing request (`GL-400-001`) | 400 |
| Card domicile or card type not configured for merchant (`GL-201-020`) | 400 |
| Duplicate `merchantUniqueId` / too many requests (`GL-400-001`) | 429 |
| Merchant is blacklisted and not permitted to transact (`GL-403-001`) | 403 |
