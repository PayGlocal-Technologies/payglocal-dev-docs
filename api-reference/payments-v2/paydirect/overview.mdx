<Warning>
  PayDirect requires **PCI DSS Level 1 certification** — your server handles raw card data. If you are not PCI certified, use [PayCollect](/api-reference/payments-v2/paycollect/overview) instead.
</Warning>

## Authentication

All PayDirect requests require RSA JWS signing. See [Authentication](/api-reference/payments-v2/common/authentication) for headers and signing details.
