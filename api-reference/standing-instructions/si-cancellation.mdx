Manage mandate lifecycle — pause, resume, or permanently cancel recurring debits.

---

## Raw Payload

| Action | Description | Reversible? |
|---|---|---|
| `REVOKE` | Permanently cancel mandate | No. New mandate required via fresh GPI. |
| `PAUSE` | Temporarily suspend debits | Yes — use `ACTIVATE` to resume. |
| `ACTIVATE` | Resume a paused mandate | N/A |

### Revoke (Permanent Cancel)

```json
{
  "merchantTxnId": "REVOKE-TXN-456789-20260523",
  "standingInstruction": {
    "action": "REVOKE",
    "mandateId": "md_94f0bb40-2664-4851-ab83-b86c618d3e15"
  }
}
```

### Pause

```json
{
  "merchantTxnId": "PAUSE-TXN-456789-20260523",
  "standingInstruction": {
    "action": "PAUSE",
    "mandateId": "md_94f0bb40-2664-4851-ab83-b86c618d3e15"
  }
}
```

### Activate (Resume Paused)

```json
{
  "merchantTxnId": "ACTIVATE-TXN-456789-20260523",
  "standingInstruction": {
    "action": "ACTIVATE",
    "mandateId": "md_94f0bb40-2664-4851-ab83-b86c618d3e15"
  }
}
```

## Token Generation

<Warning>
  **The raw payload above cannot be sent directly.** It must be encrypted and signed using the PayGlocal SDK.
</Warning>

```javascript
const { jweToken, jwsToken } = generateJWEAndJWS(
  rawPayload,   // JSON payload built above
  pubCert,      // PayGlocal's public certificate (from GCC)
  pvtKey,       // Your private key (from GCC)
  merchantId,
  pubKeyId,
  pvtKeyId
);
```

| Token | What it is | Where it goes |
|---|---|---|
| `jweToken` | Your payload, AES-256 encrypted with PayGlocal's public cert | **Request body** (`text/plain`) |
| `jwsToken` | RSA signature over the JWE token using your private key | **`x-gl-token-external` header** |

**Generated cURL request:**

```bash
curl -X PUT https://api.uat.payglocal.in/gl/v1/payments/si/status \
  -H "Content-Type: text/plain" \
  -H "x-gl-token-external: <your-jws-token>" \
  -d "<your-jwe-token>"
```

---

## Request Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `merchantTxnId` | string | Yes | Unique transaction reference for this action. |
| `standingInstruction.action` | string | Yes | `REVOKE`, `PAUSE`, or `ACTIVATE`. |
| `standingInstruction.mandateId` | string | Yes | Masked mandate ID from Get Status response. |

## Mandate State Transitions

```
              ┌─────────┐
              │  ACTIVE │
              └────┬────┘
                   │
       ┌───────────┴──────────┐
       │                      │
  PAUSE (PUT)            REVOKE (PUT)
       │                      │
       ▼                      ▼
  ┌──────────┐          ┌──────────────┐
  │ INACTIVE │          │ INACTIVE     │
  │ (paused) │          │ (permanent)  │
  └────┬─────┘          └──────────────┘
       │                (cannot reactivate)
  ACTIVATE (PUT)
       │
       ▼
  ┌─────────┐
  │  ACTIVE │
  └─────────┘
```

---

## Error Responses

| Status | Message | Action |
|---|---|---|
| `REQUEST_ERROR` | Mandate was inactive | Already paused/revoked — check status |
| `REQUEST_ERROR` | Mandate id not found | Verify mandate ID is correct |

---

## Notes

- **REVOKED** mandates are permanent. New mandate requires a new GPI payment with `standingInstruction` data
- `merchantTxnId` must be unique for each action request
- Use [SI Status](/api-reference/standing-instructions/si-status) to verify action result
