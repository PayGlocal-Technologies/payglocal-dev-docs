Retrieve current state and payment count of a Standing Instruction mandate. Call this before triggering a debit to confirm the mandate is still active.

---

## Raw Payload

```json
{
  "merchantTxnId": "STATUS-TXN-456789-20260523",
  "standingInstruction": {
    "mandateId": "md_c87fcf0a-a62c-4dae-b001-ee69fee587c3"
  }
}
```

---

## Token Generation

<Warning>
  **The raw payload above cannot be sent directly.** It must be encrypted and signed using the PayGlocal SDK.
</Warning>

```javascript
const { jweToken, jwsToken } = generateJWEAndJWS(
  rawPayload,   // JSON payload built above
  pubCert,      // PayGlocal's public certificate (from GCC)
  pvtKey,       // Your private key (from GCC)
  merchantId,
  pubKeyId,
  pvtKeyId
);
```

| Token | What it is | Where it goes |
|---|---|---|
| `jweToken` | Your payload, AES-256 encrypted with PayGlocal's public cert | **Request body** (`text/plain`) |
| `jwsToken` | RSA signature over the JWE token using your private key | **`x-gl-token-external` header** |

**Generated cURL request:**

```bash
curl -X POST https://api.uat.payglocal.in/gl/v1/payments/si/status \
  -H "Content-Type: text/plain" \
  -H "x-gl-token-external: <your-jws-token>" \
  -d "<your-jwe-token>"
```

---

## Request Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `merchantTxnId` | string | Yes | Unique transaction reference for this status check. |
| `standingInstruction.mandateId` | string | Yes | Masked mandate ID from Get Status response. |

---

## Mandate Status Values

| Status | Description | Can Charge? |
|---|---|---|
| `ACTIVE` | Live and accepting debits | Yes |
| `INACTIVE` | Paused or revoked | No. Resume via `ACTIVATE` or create new mandate. |
| `EXHAUSTED` | All payments processed | No. Create new mandate via new GPI payment. |

---

## Error Responses

| Status | Message | Action |
|---|---|---|
| `NOT_FOUND` | Mandate id not found | Verify mandate ID is correct |

---

## Notes

- `merchantTxnId` must be unique per status check request
- If `INACTIVE`, use [SI Cancel/Pause/Activate](/api-reference/standing-instructions/si-cancellation) with `action: ACTIVATE` to resume
- If `EXHAUSTED`, create a new mandate via fresh GPI payment with `standingInstruction` data
