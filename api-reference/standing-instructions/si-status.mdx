## When to Use

Call this endpoint to check whether a standing-instruction mandate is still usable before initiating a subsequent debit. Use it to confirm the mandate state (`ACTIVE`, `PAUSED`, `REVOKED`, `EXHAUSTED`), the number of payments completed so far, and the remaining payment count. Applies to both on-demand and auto-debit mandates (PayDirect and PayCollect). If the mandate is `EXHAUSTED` or `REVOKED`, do not attempt a Standing Instruction Sale — create a new mandate instead.

## Mandate Status Values

| Status | Description |
|--------|-------------|
| `ACTIVE` | Mandate is active and can be used for subsequent payments |
| `PAUSED` | Mandate has been temporarily paused and cannot be debited until resumed |
| `REVOKED` | Mandate was revoked via API or Control Center and cannot be used |
| `EXHAUSTED` | All configured payments have been processed |

## Example

<CodeGroup>

```json Request
{
  "merchantUniqueId": "si_status_check_001",
  "mandateId": "md_94fxxxxxx3e15"
}
```

```json Response (200)
{
  "status": "SUCCESS",
  "mandateData": {
    "mandateId": "md_94fxxxxxx3e15",
    "mandateStatus": "ACTIVE",
    "amount": "500.00",
    "frequency": "MONTHLY",
    "startDate": "20240101",
    "mandateCreateDate": "20231215",
    "numberOfPaymentsCompleted": 4,
    "numberOfPaymentsRemaining": 2
  }
}
```

</CodeGroup>

## Error Scenarios

| Scenario | HTTP Code |
|----------|-----------|
| `mandateId` is missing or malformed | 400 |
| Mandate not found for the given merchant | 404 |
| Authentication headers missing or invalid | 401 |
| Merchant not authorized to access this mandate | 403 |
| Downstream service unavailable | 503 |
