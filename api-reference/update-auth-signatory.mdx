---
title: "Update Authorised Signatory"
description: "Submit or update the authorised signatory's personal details, PAN, and designation for a merchant onboarding application."
openapi: "PUT /gcc/v2/partner/merchant/onboard/{onboardingId}/auth-signatory"
---

## When to Use

Submits the authorised signatory details. The signatory's phone and email are used to conduct VKYC, DigiLocker verification, and T&C acknowledgement — so accuracy is critical.

<Snippet file="tnc-lock-warning.mdx" />

## Example

<CodeGroup>

```json Request
{
  "firstName": "Priya",
  "lastName": "Sharma",
  "email": "priya.sharma@example.com",
  "phone": "9876543210",
  "pan": "ABCPS1234D",
  "designation": "Director"
}
```

```json Response (200)
{
  "status": "SUCCESS",
  "message": "Authorised signatory details updated successfully.",
  "onboardingId": "<ONBOARDING_ID>"
}
```

</CodeGroup>

## Error Scenarios

| Scenario | HTTP Code |
|----------|-----------|
| Required fields validation error | `400` |
| PAN validation failed | `400` |
| Update attempted after T&C is acknowledged | `400` |
| `onboardingId` does not exist | `404` |
| `onboardingId` does not belong to this partner | `403` |
