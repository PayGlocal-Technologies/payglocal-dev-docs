---
title: "Verify Merchant"
openapi: "PUT /gcc/v2/partner/merchant/onboard/{onboardingId}/verify"
---

## When to Use

Generates a unique, time-limited verification session URL for the merchant to complete T&C acknowledgement, DigiLocker verification, and VKYC. Embed the returned `data.redirectUrl` in an iFrame — see the [iFrame Integration](/guides/iframe-integration) guide.

<Warning>
  This endpoint can only be called after **all** prior onboarding steps are complete. Calling it earlier returns `400 Bad Request`.
</Warning>

## Notes

- `callbackUrl`'s domain must be [whitelisted](/guides/iframe-integration#step-1-domain-whitelisting-action-required) with PayGlocal before use.

## Error Scenarios

| Scenario | HTTP Code |
|----------|-----------|
| Not all onboarding info is captured | `400` |
| `onboardingId` does not exist | `404` |
| `onboardingId` does not belong to this partner | `403` |
