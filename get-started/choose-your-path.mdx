## Quick Decision Guide

<Steps>
  <Step title="Do you need to accept payments?">
    Yes — continue. No, and you need to receive foreign currency — [Multi-Currency Accounts](/mca/concepts).
  </Step>
  <Step title="Are you PCI DSS Level 1 certified?">
    **No** — Use [PayCollect](/payments/paycollect/overview) — PayGlocal's hosted checkout handles all card data. You keep minimal PCI scope (SAQ A).

    **Yes** — You can use [PayDirect](/payments/paydirect/overview) for a seamless in-page checkout experience, or [Standalone Auth/Capture](/payments/paydirect/auth-capture) if you need to pre-authorize and capture later.
  </Step>
  <Step title="Do you need recurring billing?">
    **No** — Standard GPI (one-time payment). See [Regular Payment](/payments/types/regular-payment).

    **Yes** — [Standing Instructions](/payments/types/recurring-payment) — merchant-triggered recurring charges or auto-debit schedules. Supported for international cards only.
  </Step>
  <Step title="Do you have developer resources?">
    **No** — [No-Code Payments](/payments/no-code/overview) — Payment Links and Invoice Links require no code.

    **Running WooCommerce, Magento, or Shopify?** — [E-commerce Plugins](/payments/plugins/overview).

    **Yes** — Proceed with API integration.
  </Step>
</Steps>

## Integration Mode Comparison

| | PayCollect | PayDirect | Standalone Auth/Capture | No-Code |
|---|---|---|---|---|
| Developer effort | Low | Medium | High | None |
| PCI DSS scope | SAQ A (minimal) | Level 1 (full) | Level 1 (full) | None |
| Checkout location | PayGlocal hosted | Merchant site | Merchant site | PayGlocal hosted |
| Custom UI | Limited | Full | Full | None |
| International cards | Yes | Yes | Yes | Yes |
| Alternative payment methods | Yes | No | No | Yes |
| Recurring payments (SI) | No | Yes | Yes | No |
| Auth now, capture later | No | No | Yes | No |

<Note>
  Standing Instructions (recurring billing) require your MID to be enabled for SI processing. Contact [merchant.support@payglocal.in](mailto:merchant.support@payglocal.in) to confirm eligibility before starting your integration.
</Note>

## Platform / Partner Path

Building a platform that onboards sub-merchants? You need the [Partner Onboarding API](/set-up/partner-onboarding/quickstart) — a separate API surface from the payment APIs. Payment API credentials and partner API credentials are issued independently.
