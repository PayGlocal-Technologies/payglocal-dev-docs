## Quick Comparison

|                                  | PayCollect              | PayDirect                  |
|----------------------------------|-------------------------|----------------------------|
| **PCI DSS required?**            | No                      | Yes                        |
| **Who collects card data?**      | PayGlocal (hosted page) | You                        |
| **Integration effort**           | Low (~5 minutes)        | Medium to high             |
| **UI control**                   | Limited (hosted)        | Full                       |
| **3DS authentication**           | Built in                | Built in                   |
| **International cards**          | Yes                     | Yes                        |
| **Alt payment methods**          | Yes (iDeal, Sofort, etc.) | No                       |
| **Endpoint**                     | `/gl/v1/payments/initiate/paycollect` | `/gl/v1/payments/initiate` |

## Decision Guide

```
Are you PCI DSS certified?
│
├─ NO  → PayCollect
│         PayGlocal hosts the payment page.
│         You send amount + currency; PayGlocal collects card details.
│
└─ YES → Do you need full control over the checkout UI?
          │
          ├─ YES → PayDirect
          │         You collect card data on your own page;
          │         PayGlocal processes the payment.
          │
          └─ NO  → PayCollect
                    Faster integration, less to maintain.
```
