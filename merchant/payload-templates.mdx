## Payload Templates

Select a template below to view a ready-to-use payload. Each template is the minimum required structure for that operation — add optional fields (risk data, billing data, shipping data) as your integration grows.

---

## Payment Initiation

### PayCollect — Minimum Payload

```json
{
  "merchantTxnId": "23AEE8CB6B62EE2AF07",
  "paymentData": {
    "totalAmount": "89",
    "txnCurrency": "INR"
  },
  "merchantCallbackURL": "https://www.yoursite.com/callback"
}
```

→ POST `/gl/v1/payments/initiate/paycollect`

### PayDirect — Minimum Payload

```json
{
  "merchantTxnId": "23AEE8CB6B62EE2AF07",
  "paymentData": {
    "totalAmount": "89",
    "txnCurrency": "INR",
    "cardData": {
      "number":       "5132552222223470",
      "expiryMonth":  "12",
      "expiryYear":   "2030",
      "securityCode": "123"
    }
  },
  "merchantCallbackURL": "https://www.yoursite.com/callback"
}
```

→ POST `/gl/v1/payments/initiate`

## Standing Instructions

### SI Initiate (with first payment) — FIXED Type

```json
{
  "merchantTxnId": "23AEE8CB6B62EE2AF07",
  "paymentData": {
    "totalAmount": "89",
    "txnCurrency": "USD"
  },
  "standingInstruction": {
    "data": {
      "amount":           "89",
      "numberOfPayments": "12",
      "frequency":        "MONTHLY",
      "type":             "FIXED",
      "startDate":        "20260601"
    }
  },
  "merchantCallbackURL": "https://www.yoursite.com/callback"
}
```

```json
{
  "merchantTxnId": "23AEE8CB6B62EE2AF07",
  "paymentData": {
    "totalAmount": "89",
    "txnCurrency": "USD"

    "data": {
      "amount":           "89",

      "numberOfPayments": "12",
      "frequency":        "ONDEMAND",
      "type":             "VARIABLE",
      "startDate":        "20260601"
    }
  },
  "merchantCallbackURL": "https://www.yoursite.com/callback"
}
```

### SI On-Demand Sale (VARIABLE)

```json
{
  "merchantTxnId": "SALE-23AEE8CB6B62EE2AF07",
  "paymentData":   { "totalAmount": "89" },
  "standingInstruction": {
    "mandateId": "md_94f0bb40-2664-4851-ab83-b86c618d3e15"

}
```

→ POST `/gl/v1/payments/si/sale`

## Auth & Capture

### Auth Payment (hold funds)

```json
{
  "merchantTxnId": "23AEE8CB6B62EE2AF07",
  "paymentData": {
    "totalAmount": "100.00",
    "txnCurrency": "INR",
    "cardData": {
      "number":       "4242424242424242",
      "expiryMonth":  "05",
      "expiryYear":   "2028",
      "securityCode": "173"
    }
  },
  "captureTxn": false
}
```

→ POST `/gl/v1/payments/auth`

### Full Capture

```json
{
  "merchantTxnId": "CAP-23AEE8CB6B62EE2AF07",
  "captureType":   "F"
}
```

→ POST `/gl/v1/payments/{gid}/capture`

### Partial Capture

```json
{
  "merchantTxnId": "CAP-23AEE8CB6B62EE2AF07-1",
  "captureType":   "P",
  "paymentData":   { "totalAmount": "60.00" }
}
```

### Auth Reversal

```json
{
  "merchantTxnId": "REV-23AEE8CB6B62EE2AF07"
}
```

→ POST `/gl/v1/payments/{gid}/auth-reversal`
