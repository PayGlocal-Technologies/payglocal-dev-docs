## Two Ways to Integrate

| | PayCollect | PayDirect |
|---|---|---|
| Hosted by | PayGlocal | Merchant |
| PCI DSS scope | Minimal (SAQ A eligible) | Full Level 1 required |
| Customer experience | Redirect to PayGlocal checkout | Stays on merchant site |
| Card data handling | PayGlocal handles | Merchant handles (JWE required) |
| Best for | Fast integration, lower compliance burden | Custom checkout UX, PCI-certified merchants |

## Payment Types

| Type | Description |
|---|---|
| Regular GPI | One-time payment — single charge, customer-initiated |
| Standing Instructions (SI) | Recurring billing — mandate registration + on-demand or auto-debit |
| Auth & Capture | Two-step payment — authorize a hold, capture later (hotels, marketplaces) |

## Choose Your Path

**Not PCI DSS certified?** → Use [PayCollect](/payments/paycollect/overview) — PayGlocal handles all card data.

**Need a custom checkout UI or already PCI certified?** → Use [PayDirect](/payments/paydirect/overview).

**No developer resources?** → Use [No-Code Payments](/payments/no-code/overview) — Payment Links, Invoice Links, or Payment Button.

**Running on WooCommerce, Magento, or another platform?** → Use an [E-commerce Plugin](/payments/plugins/overview).
