## What you'll need

Before starting any plugin setup, generate the required credentials from [GCC](/getting-started/gcc-dashboard):

- **API Key** — for API authentication.
- **RSA Keys** (private + PayGlocal public certificate) — for JWS token signing.

See [Key Management](/key-management/overview) for details.
