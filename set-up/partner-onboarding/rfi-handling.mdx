## What Is RFI?

RFI (Request for Information) means PayGlocal's compliance team has reviewed the merchant's onboarding application and needs additional or corrected documents before approval.

The merchant's `onboardingStatus` becomes `RFI`. This is not a rejection — the merchant can provide the requested information and the application continues.

## Step 1: Identify Required Documents

Call [Get Status](/api-reference/get-status) and inspect the `documentsToBeUploaded` array:

```javascript
const status = await getOnboardingStatus(onboardingId);
if (status.onboardingStatus === 'RFI') {
  const required = status.documentsToBeUploaded;
  console.log('Documents needed:', required);
  // e.g. ['GST_CERTIFICATE', 'CANCELLED_CHEQUE']
}
```

Each item in the array is a `merchantDocType` string. See [Upload Documents](/api-reference/upload-documents) for the full enum of document types.

## Step 2: Collect and Upload Documents

For each document type in `documentsToBeUploaded`, call POST /upload-documents:

```javascript
for (const docType of required) {
  await uploadDocument({
    onboardingId,
    merchantDocType: docType,
    fileBuffer: await getFileBuffer(docType),
  });
}
```

See [Merchant Requirements](/guides/merchant-requirements) for document format requirements and accepted file types.

## Step 3: Resume Polling

After uploading all requested documents, continue polling [Get Status](/api-reference/get-status). The status will transition:

**RFI** → **PENDING_REVIEW** (when all requested documents are received)
→ **UNDER_REVIEW** → **APPROVED** or **REJECTED**

Poll every 60 seconds. Transitions typically happen within 1–3 business days.

## Common RFI Triggers

- Blurry or low-resolution document scan
- Document name does not match the entity name on the onboarding application
- Missing GST certificate or PAN card
- Bank account does not match the registered entity name
- Cancelled cheque not signed or stamped

<Note>If you are repeatedly entering RFI for the same document type, contact merchant.support@payglocal.in for guidance on the exact specification required.</Note>
