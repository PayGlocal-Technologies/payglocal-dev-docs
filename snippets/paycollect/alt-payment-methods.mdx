PayCollect supports **Global Alternative Payment Methods** for merchants exporting goods or
services outside India:

| Category | Methods |
|---|---|
| Bank transfers | iDeal, Sofort, Trustly, giropay, EPS |
| Wallets | Various regional wallets |
| BNPL | Buy Now Pay Later providers |

For alternative payment methods, two additional fields become required:

- `riskData.shippingData.addressCountry` — destination country (ISO 3166-1 alpha-3)
- `riskData.customerData.emailId` — customer email

**Example payload for alternative payment methods:**

```json
{
  "merchantTxnId": "23AEE8CB6B62EE2AF07",
  "paymentData": {
    "totalAmount": "89",
    "txnCurrency": "INR"
  },
  "riskData": {
    "customerData": {
      "merchantAssignedCustomerId": "11230092",
      "emailId": "customer@example.com"
    },
    "shippingData": {
      "addressCountry": "USA"
    }
  },
  "merchantCallbackURL": "https://www.yoursite.com/callback"
}
```
