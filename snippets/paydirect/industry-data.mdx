For certain verticals, additional data blocks are supported inside `riskData`. Sending
industry-specific data unlocks enhanced fraud protection and may be required by acquiring banks.

| Industry | Data Block | Description |
|---|---|---|
| Airlines / OTA | `flightData[]` | Flight booking, leg details, and passenger data |
| Hospitality | `lodgingData` | Check-in / check-out dates, room type, and guest data |
| Ground Transport | `trainData[]`, `busData[]`, `cabData[]` | Journey and passenger details |

See [Risk Data Fields](/api-fields/risk-data-fields) for the complete field reference for each block.
